# [S05] Retrieval augmented generation (RAG) and indexes

- 類型：官方產品文件

- 主題：索引、embedding、混合搜尋與安全

## 來源摘記（中文意譯，非逐字轉錄）

1. RAG 可拆成 Retrieve → Augment → Generate 三階段。
2. 索引可支援關鍵字、語意、向量或混合檢索；embedding 是用於向量相似搜尋的數值表示。
3. 索引中保留標題、URL 等欄位，有助於追蹤與引用原始文件。
4. 應測試檢索品質、回答準確性與出處；檢索端也要做權限控管。
