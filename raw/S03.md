# [S03] What is retrieval augmented generation (RAG)?

- 類型：官方技術解說
- 出版者：IBM
- 原始網址：https://www.ibm.com/think/topics/retrieval-augmented-generation
- 檢視日期：2026-11-23
- 主題：四大元件、RAG 與微調

## 來源摘記（中文意譯，非逐字轉錄）

1. 常見 RAG 架構包含知識庫、檢索器、整合層與生成器。
2. 使用者提問後，檢索器找資料，再把取回的內容加入提示供語言模型作答。
3. RAG 主要補外部資訊；微調則是調整模型在領域、風格或任務上的行為，兩者可搭配。
4. 提供可點開的出處方便核對，但不能完全消除幻覺。
