# [S01] Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks

- 類型：原始研究論文
- 出版者：研究論文
- 原始網址：https://arxiv.org/abs/2005.11401
- 檢視日期：2026-11-23
- 主題：RAG 的研究起源與概念

## 來源摘記（中文意譯，非逐字轉錄）

1. RAG 以生成模型的參數化知識搭配外部、可檢索的非參數化知識。
2. 原研究以文件檢索搭配生成模型處理知識密集型任務。
3. 研究指出外部記憶可提供比單靠模型參數更容易更新的知識來源。

## 解讀時的限制

論文中的實驗結果是特定模型與資料集表現，不能直接推論「所有 RAG 都不會幻覺」。
