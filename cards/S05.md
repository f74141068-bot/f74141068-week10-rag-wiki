# 證據卡 S05｜Microsoft Learn

**資料來源：** https://learn.microsoft.com/en-us/azure/foundry/concepts/retrieval-augmented-generation?view=foundry-classic

**可支持的教學主張**

- RAG 可拆成 Retrieve → Augment → Generate 三階段。
- 索引可支援關鍵字、語意、向量或混合檢索；embedding 是用於向量相似搜尋的數值表示。
- 索引中保留標題、URL 等欄位，有助於追蹤與引用原始文件。
- 應測試檢索品質、回答準確性與出處；檢索端也要做權限控管。
