Graph 控制大流程，Loop 只修改失敗節點；與課程講義第 43–47 頁「錯在哪關，退回哪關」一致。

LOOP SPEC

完成標準

  • 來源 ≥ 5 筆、Wiki 條目 ≥ 5 篇
  • 簡報 8–15 頁且每頁有有效來源 ID
  • 所有本地連結可解析，導航按鈕與鍵盤可用
  • 來源與敘述由人核對，不能拿視覺檢查取代事實查核
STOP RULES

停止條件

  • 所有檢查通過 → 停止並交件
  • 修改滿 3 輪仍未通過 → 暫停，回報未解問題
  • 來源少於 5 筆／出現衝突 → 不強行生成
  • 外部來源不可查證 → 註明而非自動補造

每一關怎麼退回？

缺來源

某頁找不到支持證據 → 退回 N2 重新核對來源卡，不直接修漂亮句子。

文案太長

投影片溢出 → 只退回 N5 精簡那一頁，不重新 ingest 全部來源。

引用錯誤

引用不存在的 Sxx → 程式擋下 N6，回到那頁稿件補正。

檢查紀錄與限制

已提供可重跑驗證工具 scripts/validate.py 與本次測試輸出 reports/validation.txt。程式負責數量、引用及連結；語義忠實度屬人工核對項目，不能誤稱程式已完全證明。
